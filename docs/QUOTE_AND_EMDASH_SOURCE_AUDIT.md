# Audit provenance — guillemets, dialogues et tirets longs (20 octobre 2026)

**Source de vérité :** les sources Git GITenberg épinglées dans `superparser/research/verbnet_lr/corpora/manifest.json`, les quatre fichiers nettoyés qui conservent leurs SHA, puis les deux représentations `source_text` et `balanced_analysis_text` du pipeline de diagnostic.

Les empreintes Git originales, vérifiées dans les dépôts publics, correspondent aux SHA épinglés : `GITenberg/Frankenstein_84` / `84.txt` = `176b1be39b6d925277c2d3bf413959a5dae8f095` et `GITenberg/Treasure-Island_120` / `120.txt` = `5489be98377a7b4bac93b55bfb518d17cae6e68b`. Le nettoyage des romans ne remplace pas les apostrophes ni les guillemets, il enlève uniquement le paratexte Gutenberg, certains séparateurs et les balises de mise en italique.

**Garanties :** ne pas réécrire les romans nettoyés, les 500 sources sélectionnées ni les signes de ponctuation historiques. Les guillemets synthétiques restent confinés à la chaîne d'analyse et enregistrés avec `balanced_synthetic_prefix` / `balanced_synthetic_suffix`. Le signe `--` est maintenant lisible dans le treillis à la fois comme `DASH[dash_kind=em]` et comme `COMMA` ancien ; la dette de grammaire consistant à dissocier les contextes où un tiret ne doit pas être une virgule demeure à traiter. Pour la carte, une exclusion éventuelle nécessite un nouveau benchmark identifié par un nouveau SHA.
