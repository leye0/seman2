# Dialogue failure-seeking benchmark

The next target is correctness, not maximizing returned parses. The existing 20-case speaker sample is development evidence. A new 40-case sample is fixed by SHA-256 ordering of single-reporter dialogue passages not in the old sample; gold mentions and heads are annotated from the source. It is a new sample from the same already-used novels, not an independent unseen source corpus.

A separate contrastive set creates 86 paragraphs across preposed/inverted tags, reporting verbs missing from source extraction, polysemy, addressees, split control/condition, nested quotations, unrelated narration, written mentions, passive reporting, relative-clause distractors and separate turns. Expected quotations and speakers are explicit from construction, including negative controls. Count missing quote, missing attribution, wrong speaker, ambiguous speaker, unresolved speaker, and false attribution separately. No gold from the evaluation is fed to the parser. These controlled cases are deliberately hard; do not interpret scores as distributional natural-language accuracy.

Experimental selectors compare the existing policy, native rank, local native opacity followed by rank, and local native opacity with abstention on ties. They preserve all readings and do not modify production. Candidate oracle recall is an upper bound on reranking, not accuracy. Use errors to identify broad failures: missing source links, missing native speaker evidence, or wrong selection. Keep the benchmark frozen while experimenting; add unseen families before promotion.
