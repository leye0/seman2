# Seman2 — Certified C subtree replay into the vector k-best forest (research v1)

Date: 17 October 2026. Branch: `research/verbnet-left-to-right-poc`.
`main` and production defaults are unchanged.

## What is implemented

- `prepacked_witnesses.py`: a separately audited C-witness admission gate.
- `VectorGrammar.parse_lattice(..., witness_cache=...)`: optional handoff after canonical packed forest recognition and before lazy grammatical extraction.
- `_LazyMaterializer`: can replay a *certified* closed subtree as native `CompactAnalysis` / `AnalysisUse` with the original grammar rule ID and children; the resulting public tree is still a normal `ChartItem` with syntax and provenance generated by the vector materializer.
- `HybridVectorParser(..., prepacked_witnesses=True)`: opt-in research path. All other instances keep the old chart and the old materializer unchanged.
- The C matcher uses the exact lattice of lexical alternatives produced by Seman2. C's incomplete/beam-limited results are suggestions only.

A subtree is certified ONLY if the completed canonical forest contains a unique structural derivation at that node **and every descendant**: one native rule/partial path, one candidate of that category and span at leaves, identical actual candidate objects, exactly matching original rule IDs and children. The currently admitted rules have no RHS feature constraints or `requires`, and no unresolved LHS/lexical feature variables. External contexts carrying feature variables or bindings do not shortcut. An incomplete vector forest disables reuse entirely.

If any requirement fails, including ambiguity or possible agreement dependency, the unmodified native k-best extraction runs. The vector category recognizer itself still explores all categories and structural alternatives. **This is a conservative extraction shortcut, not yet the more ambitious selective fast recognizer that avoids constructing internal chart states.**

## Measurement and safety

`test_verbnet_lr_prepacked_witnesses.py` exercises:
- A synthetic unique two-leaf tree whose native unification counter must decrease, with identical scores, trees, syntax and forest counts.
- Two rule alternatives at the same span: no shortcut, both alternatives present.
- An RHS feature constraint: shortcut prohibited, normal parser retained.
- Actual WordNet-based Seman2 sentences, grammar and lexical alternatives.

`benchmark_prepacked_witnesses.py` evaluates three arms with the same 50 development sentences and 70 unseen validation/holdout cases plus all 24 bad/good minimal pairs: canonical, C-agenda only, and C-agenda + certified subtree replay. It compares completion, first two normalized syntax trees, scores, lexical category multiplicities, full structural and partial forest counts, and budget status.

Native counters report recognition operations, chart partial proposals, lazy unification attempts, visited combinations, initialized nodes and compact analyses. **Only the native-counter delta vs the agenda-only arm counts as avoided grammatical work.** The C matcher time is separately measured AND included in end-to-end latency. No inference of speed from a numerical counter alone.

`benchmark_prepacked_gutenberg.py` evaluates on complete Project Gutenberg books without writing copyright text to the report: up to 5,000 candidate-training sentences from twelve novels, then roughly 1,000 stratified held-out sentences from *Jane Eyre* and *Middlemarch*, whose authors are unseen during training. Full 1,000-sentence coverage depends on corpus-extraction counts. The books are downloaded at benchmark time, with SHA-256 metadata; output contains no novel text. Unlike annotated gold, automatically parsed training sentences only provide **candidate** evidence. Structural parity and native operations are measured by token-length band.

### Reproduce

With `WORDNET_DICT` pointing to an existing WordNet 3.0 dictionary:

```bash
WORDNET_DICT=/path/to/wordnet/dict PYTHONPATH=superparser python -m unittest \
  superparser.tests.test_verbnet_lr_prepacked_witnesses -v

PYTHONPATH=superparser python superparser/scripts/benchmark_prepacked_witnesses.py \
  --wordnet-dir /path/to/wordnet/dict \
  --out /tmp/seman2-prepacked-AB.json

PYTHONPATH=superparser python superparser/scripts/benchmark_prepacked_gutenberg.py \
  --wordnet-dir /path/to/wordnet/dict \
  --max-train 5000 --per-book-per-band 125 \
  --out /tmp/seman2-prepacked-Gutenberg.json
```

GitHub workflow `.github/workflows/prepacked-subtrees-validation.yml`
runs the unit tests and reproducible short A/B benchmark on push, with an
artifact containing counter and latency measurements. **A file being
committed does not establish that CI passed. Consult the GitHub run result.**

## Next decision gate

1. Confirm CI green and zero mismatches; inspect the counts and distinguish actual savings from C-matcher overhead.
2. Run the full cross-author Gutenberg evaluation; do not promote any result from a corpus used to learn weights to a generalization claim.
3. If the overly conservative uniqueness/context proof yields negligible reuse, extend the representation to **packed contextual derivations**, with explicit feature interfaces and child provenance. Prove k-best and forest completeness before skipping any chart work.
4. Only after this can we attempt to skip *recognition* operations, not merely grammatical reconstruction; measure end-to-end p50/p95/p99, memory, correctness and training-time overhead.
5. Keep learning online, candidate/verified provenance separate, and all lexical/syntactic alternatives recoverable; do not infer grammar truth from pattern frequency.

The experimentally important question is whether verified structural reuse wins on unseen authors **including all matching overhead**. These scripts measure it; they do not assume the answer.
