# Protocole

Invariants :

1. une proposition absente du second état devient `unmentioned_after`, jamais
   une suppression ou une négation ;
2. seul un énoncé de polarité opposée produit un renversement explicite ;
3. les identifiants de référents résolus en amont sont conservés ;
4. hypothèses et questions n'entrent pas dans l'état asserté ;
5. sources différentes et temps inversé restent incomparables ;
6. un état contradictoire est refusé.
