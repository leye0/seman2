# Analyse

Les 849 observations produisent 848 comparaisons, toutes valides : 3 030
contraintes ajoutées, 3 029 non mentionnées ensuite et zéro disparition
hallucinée. Aucun maintien ni renversement exact n'apparaît entre descriptions
consécutives.

Le résultat valide le traitement monde ouvert mais ne démontre pas encore un
suivi narratif riche. La tranche porte sur des descriptions rapportées, pas sur
des états physiques.
