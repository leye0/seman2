# Verdict provisoire

`GO` — périmètre structurel compact v0.2

La projection structurelle est déterministe, sérialisable, reconstructible et
décontaminée sur le corpus diagnostique et sur les 500 premières lignes du
roman. Une seule analyse finale est conservée par observation, avec marquage
explicite des replis provisoires. Les mentions et contraintes de référence
restent disponibles.

Le GO autorise le POC-01 ; il ne fige pas une API de production. Le résultat
brut, la forêt, les scores, les bindings runtime et les graphes sémantiques
restent hors du round-trip. Les performances sont
mesurées mais aucun seuil de production n'est revendiqué.
