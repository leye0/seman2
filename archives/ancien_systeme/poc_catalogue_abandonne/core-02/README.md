# CORE-02 — Curriculum gardé et réponse autobiographique structurée

Cette POC vérifie les contrats qui entourent le développement par échelons et
le mode chatbot :

- critères et seuils fixés avant le résultat;
- probes tenus à l'écart des expériences d'apprentissage;
- questions tutorales limitées au contenu effectivement présenté;
- évaluateur externe incapable d'écrire dans le runtime;
- renforcement ciblé lorsqu'une gate échoue;
- réponses différentes pour deux biographies cognitives différentes;
- ignorance explicite, statut épistémique et provenance;
- impossibilité de récupérer un contenu oublié via l'univers d'audit.

Les tests sont formels et légers. Cette POC ne prétend pas encore réaliser une
réponse en langue naturelle ni boucler tout le flow d'ingestion.
