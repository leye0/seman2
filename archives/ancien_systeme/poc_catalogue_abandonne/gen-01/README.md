# GEN-01 — Capacités de SimpleNLG

Le POC compile et exécute quatorze structures contre le JAR SimpleNLG 4.5.0 :
temps, aspects, négation, nombre/personne, coordination, subordination,
interrogation et deux entrées incomplètes. Les traits fournis et sorties exactes
sont archivés dans la matrice de résultats.

```bash
./poc/gen-01/run.sh
```
