# CULT-04 — Dépendance contextuelle et transmission

Le POC part d'une forme exactement dupliquée dans deux communautés Reddit et
ajoute des observations contrôlées, explicitement marquées comme telles, pour
éprouver périodes, registres, relations, chaînes de transmission et exceptions.
Le retrieval compare plusieurs dimensions du contexte; aucun attribut global de
« culture » ou de membre ne détermine une intention.

```bash
./poc/cult-04/run.sh
```
