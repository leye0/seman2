# SEM-06 — Acquisition progressive d'une relation sémiotique

Trente-six événements chronologiques multi-locuteurs/domaines entrent comme de
vraies observations `Source`, puis deviennent épisodes, statistiques,
hypothèses factorisées et versions d'une relation sémiotique anonyme. Trois
corrections arrivent ensuite comme observations append-only : aucun épisode
historique n'est réécrit.

Le cluster de formes et la forme réservée `yo` proviennent réellement de
SEM-05. Les seuils et invariants de SEM-05, IND-03→06 et HYP-01→06 sont lus et
vérifiés, pas seulement mentionnés. Une occurrence tardive réservée teste la
généralisation sans taxonomie culturelle ou lexicale imposée; DuckDB recalcule
indépendamment les statistiques produites par le runtime.

```bash
./poc/sem-06/run.sh
```
