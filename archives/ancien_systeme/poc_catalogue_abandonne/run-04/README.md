# RUN-04 — Contrôle des transformations sur matière émergente

Cette POC ingère une vraie question et une vraie réponse Stack Overflow, puis
utilise uniquement les artefacts produits par la verticale bottom-up pour
construire des opérations concurrentes de consolidation. Les candidats
`retain-episode` et `defer-consolidation`, ainsi qu'un éventuel candidat
d'activation de motifs appris, pointent vers leurs préconditions cognitives et
ne copient ni texte brut ni label du corpus.

Un vrai agent Soar sélectionne l'opération mémoire préférée. Cette sélection
est opérationnelle : elle ne choisit aucune lecture comme vérité et
n'engage aucune branche du monde. Un second scénario ne fournit aucun candidat
admissible et doit rester sans décision plutôt que recevoir un choix par défaut.
