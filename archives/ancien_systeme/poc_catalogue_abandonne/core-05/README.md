# CORE-05 — Composition copulaire réelle et connaissance relationnelle

Cette POC vérifie le premier apprentissage sémantique complet du nouveau cœur :

```text
expériences linguistiques
  → ACE/ERG et MRS
  → patron grammatical copulaire ARG1/ARG2
  → candidat relationnel kind-of
  → admission après répétition indépendante
  → réponse depuis la mémoire interne
```

Le patron est d'abord testé avec `wug` et `dax`. Il ne contient donc aucune
fonction spéciale pour `apple` ou `fruit`. Les analyses alternatives d'une même
expérience ne peuvent pas gonfler artificiellement le support.
