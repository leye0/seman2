# GEN-04 — Apprentissage de la réalisation

Le POC analyse par ACE/ERG des réalisations contrôlées, produit des alignements
candidats vers leurs graphes symboliques et exporte les choix récurrents de
référence, registre, concision et morphosyntaxe. Il inclut plusieurs surfaces
pour une structure et une même surface pour plusieurs structures.

```bash
./poc/gen-04/run.sh
```
