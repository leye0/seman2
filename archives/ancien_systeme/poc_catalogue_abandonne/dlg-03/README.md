# DLG-03 — Complémentarité ERG / Dynamic Syntax

Chaque surface devient une observation commune, puis déclenche deux branches L2
réelles et indépendantes : ACE/ERG et Dynamic Syntax. Un système L3 publie un
`complementary-analysis-bundle` qui référence les deux artefacts sans copier ni
fusionner leurs sémantiques. La matrice compare couverture, candidats MRS,
états incrémentaux et TTR.

./poc/dlg-03/run.sh
