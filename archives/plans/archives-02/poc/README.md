# POC actives

Ce répertoire repart de zéro avec
`plans/architecture_cognitive_developpementale.md` comme seule autorité et
`plans/required_poc.md` comme ordre d'exécution.

Une POC active doit être une preuve verticale sur des artefacts réels produits
par les composants de l'étage inférieur. Les tests qui instancient directement
des objets cognitifs restent dans `tests/` et ne reçoivent pas de verdict de
POC.

L'ancien catalogue complet se trouve sous
`archives/ancien_systeme/poc_catalogue_abandonne/`. Il est consultable, mais
aucun de ses verdicts n'est actif.
