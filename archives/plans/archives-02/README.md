# Archive Seman2 V2

Ce dossier conserve la deuxième architecture, son runtime, ses POC, ses tests et
ses scripts de validation. Aucun de ces fichiers n'est importé ni appelé par le
runtime V3 actif sous `src/seman2`.

Le contenu demeure disponible comme historique d'expérimentation et comme
source ponctuelle d'idées d'ingestion; il n'a aucune autorité architecturale.
