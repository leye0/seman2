# Archives de l'ancien système

Ce répertoire contient les implémentations et preuves expérimentales retirées du
périmètre actif après l'adoption de
`plans/architecture_cognitive_developpementale.md`.

Elles peuvent être consultées pour récupérer une idée, un adaptateur ou une
mesure, mais elles ne définissent ni l'architecture, ni les dépendances, ni les
POC requises. Rien dans cette archive ne peut recevoir un verdict actif sans
être réintroduit par une POC verticale conforme au plan courant.

`ancien_systeme/poc_catalogue_abandonne/` contient l'intégralité de l'ancien
catalogue de POC, y compris les premières POC `CORE-*` qui mélangeaient tests
unitaires et preuves d'intégration. Les sous-répertoires `runtime/`, `tests/`,
`scripts/`, `plans/` et `evaluations/` conservent les autres éléments retirés du
périmètre actif.
