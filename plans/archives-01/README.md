# Archives d'architecture

Ce répertoire conserve les anciennes architectures, blueprints et l'ancien
catalogue de POC afin de préserver leur contexte historique.

Ces fichiers ne décrivent plus la cible cognitive du projet. L'architecture
active est :

```text
plans/architecture_cognitive_developpementale.md
```

Les implémentations, runners, tests et commandes de l'ancien échafaudage ont été
déplacés sous `archives/ancien_systeme/`. Rien dans ces deux archives ne fait
partie du runtime ou des POC actifs. Une réutilisation doit être réintroduite par
le graphe courant et une POC verticale `SYS-*`.
