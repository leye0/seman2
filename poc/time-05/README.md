# TIME-05 — Anaphore et relations temporelles du discours

Cette POC adapte des analyses contrôlées DRT/Temporal DRT/SDRT en hypothèses
temporelles attribuées. Elle conserve les antécédents concurrents, les relations
disjonctives, les spans et les échecs de résolution.

```bash
./poc/time-05/run.sh
```

Elle ne constitue pas encore un parseur automatique du discours temporel.
