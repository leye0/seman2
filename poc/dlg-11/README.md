# DLG-11 — Obligations discursives

Sept scénarios couvrent question/réponse, requête acceptée ou refusée,
salutation, silence, digression et requête indirecte ambiguë. Chaque obligation
candidate porte créateur, parties, contenu attendu, supports, échéance, règle
attribuée et historique. Les lectures concurrentes peuvent rester indécidées.
