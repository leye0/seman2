# COMM-01 — Plan communicatif inspectable

Cinq transformations symboliques (assertion, réponse, clarification, refus et
silence) passent par de vraies directives Soar puis par des contraintes Z3.
Le résultat est un plan prélinguistique explicite : but, contenu ordonné et
omis, engagements, références, quantité, style, initiative, morphosyntaxe et
provenance. Aucun générateur de texte n'est appelé.
