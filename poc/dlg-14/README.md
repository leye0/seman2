# DLG-14 — Scénarios multi-tours formels

Huit scénarios relient les contrats DLG-01 à DLG-13, SEM-01 à SEM-06 et
HYP-01 à HYP-08. Chaque tour conserve l'observation, les analyses attribuées,
l'état public avant/après, les candidats ISU, la décision, les hypothèses
cognitives, la composition demandée, le beam, le ledger et toute rupture.

```bash
./poc/dlg-14/run.sh
```

Les fixtures contrôlées testent l'intégration; les sorties externes et corpus
restent référencées par sélecteur et SHA-256, sans être promues en vérités.
