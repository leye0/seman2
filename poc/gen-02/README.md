# GEN-02 — Couverture linguistique

Le POC inspecte les classes/lexiques du JAR et exécute les mêmes structures en
anglais et avec des lexèmes français. La présence d'une chaîne en sortie n'est
pas confondue avec un support linguistique : conjugaison, accord et négation
sont comparés aux formes françaises attendues.

```bash
./poc/gen-02/run.sh
```
